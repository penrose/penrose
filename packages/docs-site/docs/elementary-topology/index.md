# Elementary Topology

Michael C. Gemignani · Second edition

This edition is being re-illustrated with Penrose. Its diagrams are written as
mathematical programs that reuse TypeScript domains and TSX styles. The book's
prose, notation, and figure geometry guide each reproduction; pale orange region
fills form a consistent visual vocabulary.

[Read the supplied book](./reader) · [Use the TSX library](./api)

## Transcribed sections

- [Front matter](./front-matter/) — title, publication, dedication, preface and original contents.

- [1 Preliminaries](./chapter-01/) — sets and functions, orderings and equivalence
  relations, cardinality, and groups; all supplied chapter text and exercises.
- [2 Metric Spaces](./chapter-02/) — metrics, neighborhoods, open and closed sets,
  convergence, continuity, and distance between sets; all supplied chapter text.
- [3 Topologies](./chapter-03/) — topologies, bases, subbases, neighborhoods, and
  derived sets; all supplied chapter text.
- [4 Derived Topological Spaces. Continuity](./chapter-04/) — subspaces,
  continuity, homeomorphisms, identifications, and products; all supplied chapter text.
- [5 The Separation Axioms](./chapter-05/) — separation, regularity, normality,
  and extension of functions; all supplied chapter text.
- [6 Convergence](./chapter-06/) — directed sets, nets, subnets, limits, filters,
  and ultrafilters; all supplied chapter text.
- [7 Covering Properties](./chapter-07/) — open covers, refinements,
  countability, compactness, and derived spaces; all supplied chapter text.

- [8 More About Compactness](./chapter-08/) — Euclidean compactness, local compactness,
  compactifications, and sequential and countable compactness; all supplied chapter text.

- [9 Connectedness](./chapter-09/) — connectedness, components and local connectedness; all supplied chapter text.
- [10 Metrizability. Complete Metric Spaces](./chapter-10/) — metrization, Cauchy sequences, completeness, Baire category and paracompactness; all supplied chapter text.
- [11 Introduction to Homotopy Theory](./chapter-11/) — homotopies, loops and the fundamental group; all supplied chapter text.
- [Appendix and indexes](./back-matter/) — infinite products, the symbol index and the subject index.
